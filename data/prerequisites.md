# Prerequisites and Programming Experience

## Course: First Steps in Python for Finance + AI

No prior programming experience is required. The course is suitable for beginners who have never programmed or used a Python script.

The course is also intended for people with some programming experience who want to continue learning. It is aimed at a general audience interested in developing technical skills for direct or indirect use at work.

The course introduces Python programming with applications to finance and artificial intelligence.
